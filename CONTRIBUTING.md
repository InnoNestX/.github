# Contributing to InnoNestX

Thanks for helping improve InnoNestX projects.

## Where to contribute

| Topic | Where |
|-------|--------|
| Bug / feature for one project | That project's Issues & Pull Requests |
| Docs / demo / API feedback | That project's Issues or Discussions |
| Org profile, funding, cross-project ideas | [InnoNestX/.github](https://github.com/InnoNestX/.github) Discussions or PRs |

## Pull request checklist

1. Fork the target repository and create a focused branch
2. Keep changes scoped — one concern per PR when possible
3. Update docs when behavior or public APIs change
4. Link related issues in the PR description
5. Be ready to iterate on review feedback

## First contribution

Look for labels such as `good first issue` or `help wanted`. Comment on the issue before starting larger work so maintainers can coordinate.

## Conduct

Be respectful and constructive. Assume good intent; disagree on ideas, not people.
