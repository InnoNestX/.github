# Security Policy

## Supported Projects

Security reports are welcome for all public InnoNestX repositories, including:

- [docker-hub-pull-counter](https://github.com/InnoNestX/docker-hub-pull-counter)
- [GlobalPulse](https://github.com/InnoNestX/GlobalPulse)
- [trading-assistant](https://github.com/InnoNestX/trading-assistant)
- [testcase-generator](https://github.com/InnoNestX/testcase-generator)

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Email: [mail@xuxuclassmate.com](mailto:mail@xuxuclassmate.com)

Include:

1. Affected repository and version / commit if known
2. Description of the issue and impact
3. Steps to reproduce or a proof of concept
4. Any suggested fixes (optional)

We aim to acknowledge reports within a few days and will coordinate disclosure after a fix is available when appropriate.
